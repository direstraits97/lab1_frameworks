Publicering

Github Pages

För att publicera denna webbsida har jag använt Github Pages. Det är en tjänst som erbjuds av Github där man kan publicera statiska webbplatser. Programmeringsspråken som kan användas är begränsade till frontend-utveckling, vilket innebär HTML, CSS och JavaScript. Publiceringstjänsten stöttar alltså inte server-baserade språk. Github Pages är gratis att använda, men med alternativa betalplaner som Team eller Enterprise för Github så får man mer kontroll över repot webbsidan bygger på, till exempel att repot kan vara privat. Team kostar 4$/mån och Enterprise kostar 21$/mån. Om man arbetar med versionshantering och använder Github är processen enkel, och som tidigare nämnt gratis. En nackdel kan vara begränsningen i vilka typer av webbsidor man kan publicera, eftersom att de endast kan vara statiska.

Jag började med att skapa ett repository på mitt Github-konto med en extra gren för development. När allt innehåll på webbsidan var klart så gjordes en push till main-grenen. Sedan inom inställningar för det repot kunde man aktivera Github Pages genom att välja vilken gren som ska användas.
